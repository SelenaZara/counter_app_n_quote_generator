# counter_app_n_quote_generator

A simple cross-platform mobile application built with **Flutter** and **Dart**. This app presents users with randomized inspirational quotes while keeping track of how many quotes have been viewed.

## 🛠️ Built With
* [Flutter](https://flutter.dev/) - Cross-platform UI toolkit
* [Dart](https://dart.dev/) - Programming language

## ✨ Features
* **Quote Generator:** Displays inspirational quotes in an elegant card UI.
* **Interactive Counter:** Tracks and displays the total number of quotes viewed.
* **Material Design 3:** Styled with dynamic color themes and smooth component layouts.
* **State Management:** Built using Flutter's `StatefulWidget` and `setState` reactivity.
